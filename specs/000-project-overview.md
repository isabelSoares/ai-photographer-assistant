# AI Photography Assistant — Project Overview

## Goal
Help photographers understand and improve their images through AI-generated feedback.

## Initial capabilities
- Accept an uploaded image
- Run image detection / visual analysis
- Present understandable observations
- Suggest practical photography improvements

## Principles
- Clearly separate detected facts from creative suggestions.
- Do not present uncertain detections as certain.
- Keep feedback actionable and respectful.
- Preserve the original image; analysis must be non-destructive.

## Out of scope for the first version
- Editing images automatically
- Maintaining a social feed or portfolio
- Professional-grade image retouching
